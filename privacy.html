Політика конфіденційності TREBA Backup Ops

Ця політика описує службовий інструмент TREBA Backup Ops і не замінює політику маркетплейсу ТРЕБА. Інструмент використовується лише власником для резервування та відновлення.

Доступ до Google Drive. Після згоди власника інструмент використовує drive.file. Цей дозвіл охоплює файли, створені застосунком або явно надані йому власником; він не є дозволом на всі файли акаунта. Додатково реалізація обмежує завантаження визначеною папкою резервування. Інструмент читає необхідні метадані папки й файлів, їхні права, розміри, контрольні суми та доступну квоту сховища. Приватність папки перевіряється перед перенесенням.

Мета обробки. Створення зовнішньої копії, перевірка цілісності, контроль успішності й можливість відновлення. Архіви шифруються до відправлення в Drive. Під час перевірки з Drive завантажується зашифрований вміст. Ключ розшифрування зберігається окремо від архівів.

Де обробляються дані. Google Drive зберігає зашифровані архіви й супровідні контрольні суми. Приватний GitHub Actions виконує резервування, зберігає налаштовані секрети та зашифровані артефакти. Supabase є джерелом даних. Healthchecks отримує службовий сигнал про завершення перевірки, без вмісту резервної копії. Ці провайдери обробляють необхідні технічні дані згідно зі своїми умовами.

Обмеження використання. Дані Google не продаються, не використовуються для реклами або навчання моделей ШІ. TREBA Backup Ops дотримується Google API Services User Data Policy, зокрема вимог Limited Use: Google API Services User Data Policy .

Строки зберігання. Зашифровані артефакти GitHub налаштовані на 30 днів. Копії в Drive зберігаються щонайменше 35 днів; поточна реалізація не видаляє їх автоматично. Власник контролює вільне місце та видалення старих архівів. Відкликання OAuth не видаляє вже створені копії.

Відкликання і видалення. Власник може відкликати доступ TREBA Backup Ops у налаштуваннях Google-акаунта, видалити OAuth-секрети в приватному ops-репозиторії та вручну видалити архіви. Для зупинки регулярних запусків потрібно також вимкнути відповідний розклад після його активації. Наразі розклади вимкнені.

Інформаційний сайт. Сторінки не містять форм, рекламних пікселів або прикладної аналітики. Хостинг може обробляти стандартні технічні дані HTTP-запитів для доставки сторінок і безпеки. Секрети та архіви через ці сторінки не передаються.
