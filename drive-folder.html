TREBA Backup Ops

Дозволити доступ до папки резервування

Вибір зі списку папок. У вікні Google виділіть наявну папку TREBA backups і підтвердіть доступ.

Вставте лише Client ID. Паролі, Client Secret, JSON і токени на цій сторінці не потрібні. Вхід і вибір папки відбудуться на сайті Google.

Значення client_id з наявного OAuth-клієнта TREBA Backup Ops.

Буде запитано лише drive.file з вибором папки. Після підтвердження Google поверне вас до OAuth Playground.

Вибрати папку в Google

Виберіть Google-акаунт, у якому зберігається папка TREBA backups. Виділіть саме цю папку у списку й натисніть кнопку підтвердження. Якщо відкрився її вміст, поверніться до списку через «Google Диск».

Що зробити після вибору папки
  1. У OAuth Playground перевірте, що в ⚙️ увімкнено Use your own OAuth credentials і вказано той самий клієнт.
  2. Натисніть Exchange authorization code for tokens.
  3. Новий Refresh token збережіть у вже наявному GitHub Secret TREBA_DRIVE_REFRESH_TOKEN.

Успішний вибір папки ще потребує перевірки доступу. Ця сторінка не запускає резервування.

Сторінка не зберігає введені дані й не обмінює коди на токени. Конфіденційність
